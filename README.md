### // Commercial & Enterprise Highlights

#### Waskita Beton Precast
*Lead Architecture & Cloud Migration (State-Owned Enterprise)*

* **Context:** Modernization of the mission-critical core asset tracking and logistics infrastructure.
* **Engineering Action:** Architected and executed a zero-downtime migration of the legacy monolith into containerized Laravel and Docker environments on hardened Linux nodes. Normalized relational schemas and introduced automated background queue processing.
* **Measurable Impact:** Achieved 100% data integrity across 100,000+ asset tracking records during live cutover, reduced reporting query latency by 55%, and eliminated legacy security vulnerabilities.

#### Harmony Kids School ERP
*Full Stack Systems Engineer*

* **Context:** Multi-branch education administration platform requiring automated parent communication, billing, and strict tenant isolation.
* **Engineering Action:** Built an automated asynchronous WhatsApp notification gateway with queue-based rate limiting, designed a dual-entry student savings accounting engine, and implemented tenant-isolated database access layers.
* **Measurable Impact:** Consolidated operations across multiple physical branches into a single real-time dashboard with sub-100ms financial calculation queries and zero cross-tenant data leakage.

#### Carivendor B2B Marketplace
*Cloud & Backend Infrastructure Engineer*

* **Context:** Enterprise B2B trading platform subject to high transactional concurrency and checkout bottlenecks during peak procurement windows.
* **Engineering Action:** Deployed an auto-scaling AWS infrastructure using Docker containers, managed RDS PostgreSQL, and S3 asset pipelines. Refactored critical database indexing paths and implemented idempotent PayPal webhook reconciliation.
* **Measurable Impact:** Reduced peak checkout latency by 35%, eliminated payment race conditions, and reduced infrastructure idle costs through dynamic auto-scaling rules.

#### TomatoSuki Stream Engine
*Systems & High-Throughput Backend Engineer*

* **Context:** Low-latency media delivery API microservice requiring sustained concurrent stream processing without process overhead.
* **Engineering Action:** Engineered a custom API gateway using the Bun runtime and ElysiaJS, taking advantage of native TypeScript execution, zero-copy routing, and lean memory footprint.
* **Measurable Impact:** Delivered 3x faster response times and a 60% lower memory footprint compared to previous Node.js and Express benchmarks under identical concurrency tests.
